# Character authoring sources

The production masters are the 269 native PNGs in `Fighters/*/frames/`, the five manifests and nine native portraits. Preserve their 256 × 256 canvas, origin (128, 232), hard alpha and shared fighter palettes.

`Generated/` includes all five front/side/back identity sheets, five portrait originals, five idle studies, five active-special studies, four champion studies and Greta's overhand study. Other large intermediates are omitted, as permitted by the brief. These high-resolution studies are authoring references; use the final native art in the game.

The recovered JSON records document identity prompts, individual frame jobs, correction prompts, one-per-fighter scale calibration, integer registration, animation edits, champion chain placements and throw contact points. They describe the earlier authoring session, not operations to repeat during integration. Some paths refer to omitted intermediate pose guides or large originals. Do not apply the historical calibration to the already registered native frames.

Idle and champion breathing preserve planted feet. Walk counterpart phases and chamber/recovery corrections include native pixel edits, as recorded. The Broker has no champion frames. Venue images, crowd sources and venue generation records are excluded from this character-only drop.

No new raster artwork was generated in the recovery pass. Native frames and portraits are retained byte-for-byte from the recovered V3 archive; packed atlas output and validation were regenerated against the latest supplied project tools.

`Palettes/` contains exact per-fighter GIMP palette swatches extracted from the delivered frames and portraits (37 colours each; Broker 38). These are authoring aids, not replacements for the project master palette.
